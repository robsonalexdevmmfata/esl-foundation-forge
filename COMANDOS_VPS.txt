3. COMANDOS PARA EXECUTAR (COPIE E COLE UM POR VEZ)
────────────────────────────────────────────────────────────────

# Ir para o diretório do projeto
cd /var/www/esl-foundation-forge
# (ou o caminho onde está o projeto)

# Instalar novas dependências (bcrypt e pg)
npm install

# Testar conexão com banco de dados
npm run db:test

# Se der erro de conexão, ajuste a senha no .env:
nano .env
# Edite a linha DATABASE_URL com a senha correta
# Ctrl+O para salvar, Enter, Ctrl+X para sair

# Executar migração (criar tabela admin_users)
npm run db:migrate

# Fazer build do projeto
npm run build

# Reiniciar PM2
pm2 restart esl-foundation-forge

# Ver logs para conferir se deu certo
pm2 logs esl-foundation-forge --lines 50

═══════════════════════════════════════════════════════════════
  ERROS COMUNS E SOLUÇÕES
═══════════════════════════════════════════════════════════════

❌ "DATABASE_URL is not configured"
→ Arquivo .env não foi enviado ou não tem a variável
→ Solução: Enviar .env via FileZilla

❌ "password authentication failed"
→ Senha do PostgreSQL está errada no .env
→ Solução: Editar .env com senha correta (320809)

❌ "relation admin_users does not exist"
→ Migração não foi executada
→ Solução: npm run db:migrate

❌ "Usuário ou senha inválidos" no login
→ Usuário admin não foi criado no banco
→ Solução: npm run admin:manage (opção 1)

❌ PM2 não reinicia
→ Usar: pm2 delete esl-foundation-forge
→ Depois: pm2 start dist/server/index.mjs --name esl-foundation-forge
